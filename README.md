# second_brain_app

Second Brain is a local-first personal vault for notes, passwords, events, and documents.

## AI Assistant

- Ask natural language questions about your stored data.
- Runs on-device using local retrieval and parsing logic (no cloud API required).
- Can create new vault items from natural language commands.

Example prompts:

- What's my HDFC account number?
- When is my passport expiring?
- Add a new note with title "Meeting with John" and content "Discussed project timeline"
- Add a new password with account name "Facebook" and username "myusername" and password "mypassword"
- Add a new event with title "Meeting with John" and date "2022-01-01" and time "10:00" and description "Discussed project timeline"
- Add a new document with title "Meeting with John" and content "Discussed project timeline"

## Getting Started

```bash
flutter pub get
flutter run
```
